# 같이마크 다운로드

친구와 같은 모드로 마인크래프트를 하게 해 주는 Windows 앱입니다. 방장이 모드를 바꾸면 친구들 컴퓨터에도 자동으로 반영됩니다.

- **받기:** [Releases](../../releases/latest)에서 `gatchimc.exe`를 받아 실행하세요. 보통은 방장이 보낸 링크의 [같이마크 받기] 버튼으로 받습니다.
- "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누르세요. 아직 코드 서명이 없는 새 프로그램이라 뜨는 안내입니다.
- 사용자 폴더에만 설치되고 관리자 권한이 필요 없습니다. 제거는 Windows 설정 → 앱에서 "같이마크"를 지우면 됩니다.
- 필요한 것: 마인크래프트 자바 에디션 계정과 공식 런처(TLauncher 등 다른 런처도 가능).
